# Bounded creative protocol ABP-CREATIVE-001

Depends on the [read-only Issue #149 proof](instagram-growth-outlier-research.md).
This protocol was introduced as opt-in; a separately reviewed default activation now permits guarded graphics production unless explicitly disabled in local configuration. Issue #149 requires
strategic review before merge; it does not require individual video approval.

## Tests and boundaries

Every new protocol concept freezes its intended viewer, specific problem,
promised payoff, single primary factor, arm, hypothesis, source, hook structure,
caption strategy and research origin before rendering. The payoff is an
attributed perspective with its conditions, never a guaranteed life outcome.

| Factor | Control | Treatment | Hypothesis |
|---|---|---|---|
| Audience | Someone making a choice | Someone reassessing an earlier choice | Decision-stage positioning changes qualified discovery and follower context. |
| Hook | Diagnostic question before an attributed perspective | Attributed exact source statement before the complete perspective | A statement-first structure earns more qualified discovery than a question-first structure. |
| Caption | Reflection prompt | Invitation to examine the full owned article | A full-context invitation produces more qualified owned-site outcomes. |
| Research | Article-first question structure | Original source-first structure informed by a verified relative outlier's caption pattern | External structural evidence improves bounded follow-up selection over the article-first control. |

Only a subset of exploration enters these trials. Planned 60/25/15 allocation,
article-first controls remain. Trial voices, graphics and caption segmentation
are held constant where possible. This production protocol is graphics-only;
new native-presenter experiments cannot be admitted. Historical matched-format
results remain one idea rather than independent replications. Different
claims are used between arms; the duplicate exception remains limited to the
existing exact matched format pair.

Each arm stops at three graphics posts from three distinct claims. Arms
may run concurrently. Selection balances source-article/topic blocks; analysis
also records the preregistered UTC six-hour bin from actual publication
receipts. There is no fixed content calendar or new schedule. Actual durations,
voices, formats, CTA, missing blocks and target-age eligibility remain visible.
Limited source supply can leave a trial incomplete; it never lowers admission
standards or authorizes repeats. The strict archive currently supplies only
14 eligible owned paragraphs plus the existing vetted reference set.

## Admission and compatibility

The complete original paragraph remains unchanged in the explanatory beats.
The new statement-first hook repeats its exact first sentence with explicit
Leon Lin attribution. No model or competitor supplies factual prose. Existing
scope/rights exclusions, source hashes, independent ASR and audible qualifiers,
technical QA, fictional-presenter provenance, byte hashes, signatures, CAS,
kill switches and <=3 ordinary Reels/rolling 24h with >=3h spacing remain.

New metadata and captions must reconstruct exactly. Existing released V1
envelopes are never rewritten or re-signed: the two frozen protected-main V1 runtime releases (original and guarded GPU
graphics), with their unchanged source policy, remain valid **only** after unchanged V1 reconstruction.
It cannot validate new creative fields or arbitrary historical runtimes. A
genuine published V1 canary receipt is a public regression fixture, alongside
negative cases for mixed digests, changed content and forged fields.

New arm source URLs carry fixed ABP campaign tags and concept IDs, using the
site's existing append-once first-touch attribution. Canonical source URLs stay
untagged. Instagram caption URLs are not represented as clickable links. Tags
can attribute a preserved copied URL; untagged/profile traffic cannot be assigned
to an arm. The protocol does not modify a profile link or claim that one was
verified. No viewer identifier, tracking pixel or newsletter send is added.

## Native source typography (issue #150; offline pending #160)

`typography` is an additional frozen `ABP-CREATIVE-001` factor, not a new
renderer or an iart dependency. Both arms compile identical narration, voice,
scene timing and captions. Control uses `cards`; treatment uses `source_type`.
Single-sentence paragraphs use the already supported compact narration in both
arms. The complete source paragraph, attribution and qualifications remain
unchanged. Reference scripts and presenter experiments are outside this lane.

The native renderer displays **complete source sentences**, never standalone
comma fragments. All words of the current sentence remain visible while actual
aligned word times drive emphasis. Context-dependent follow-on sentences (such as “This implies”, “If”, or “But”)
stay with the preceding sentence rather than losing their antecedent. The next
independent sentence group appears at its measured start. Type fits in the existing safe area before encoding, with a 38px floor;
whole sentences that cannot fit or exceed 5.5 spoken words/second fail visibly.
No estimated rotation clock, missing-condition excerpts, new factual labels,
model judgment, new assets or inference models are introduced. Existing
captions, disclosure, audio normalization, encoding and every-frame bounds checks
remain authoritative. Failure quarantines the candidate; it does not publish a
control under a treatment identity.

The source/timing plan and readable layout are recorded in the normal media
manifest and independently checked by admission QA. The new module is included
in the runtime digest. Exact protected-main #161 admissions retain compatibility
only for the old factor allowlist; mixing release digests or using those
signatures for typography is refused.

**Live activation is blocked**, even with a signing key: `require_live_evidence`
raises `source_type_waiting_for_treatment_identity`. The normal selector does
not choose this factor. Main lacks #160's versioned treatment identity,
source-aware reuse spacing and matched visual controls. Do not remove this gate
by setting a local flag, editing a manifest or relabeling existing videos.
No timer, production allocation or individual-video approval has been added.

After #160 is ready, a separate verified activation can use the existing
three-distinct-claims-per-arm cap: three matched source claims, control versus
source typography, same audio/timing/CTA, balanced existing publication slots,
60/25/15 allocation, <=3 ordinary Reels per rolling day and >=3h spacing. Existing
source, rights, duplicate/media, quota, kill switch and GPU safeguards still
apply. Same-age 24h/48h/7d measurements feed the existing weekly scorecard's
creative-factor aggregation. Missing metrics remain unavailable; inconclusive
attention evidence never establishes a follower-growth winner. No live metric
is claimed by offline rendering or the synthetic scorecard tests.

stops the command. Choose another output directory for a reproducibility run;
completed outputs are never silently overwritten. Local files remain ignored.
