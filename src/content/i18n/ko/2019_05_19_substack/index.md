저는 [previously described](/writing/write 'why write') 공개 블로그를 시작하게 된 이유들입니다\. 이 웹사이트 외에도 최근에 Substack에 가입하여 제 블로그를 게시했습니다 [monthly newsletters](https://avoidboringpeople.substack.com/ 'substack')\. Substack 이전에는 배포 목록에 직접 이메일을 보내곤 했습니다\.

이 글에서는 다음과 같이 설명합니다\:

1. 제가 개인 이메일에서 Substack으로 옮긴 이유
2. Substack의 다른 장점
3. 제품의 가능한 개선 사항
4. 다른 더 가능성 낮은 제안들

## 저는 다음과 같은 혜택 때문에 Substack으로 옮겼습니다

1. 매번 이메일을 복사해서 붙여넣는 것보다 이메일 리스트를 더 쉽게 관리할 수 있는 방법으로\, 구독자를 포함하거나 삭제하는 것을 잊을 가능성을 줄여줍니다\.

   > Substack을 통해 메일링 리스트를 만들고 언제든지 가져갈 수 있습니다\. 이미 메일링 리스트가 있다면 버튼 한 번으로 설정에서 가져올 수 있습니다\.

   ![post](../../../blog/2019_05_19_substack/s_1.webp)

   목록을 가져오면 각 개별 구독자의 상태와 최근 활동을 확인할 수 있습니다

   ![post](../../../blog/2019_05_19_substack/s_2.webp)

   그리고 각 구독자 이름을 클릭하면 더 자세한 정보를 보고 구독 유형을 편집할 수 있습니다

   ![post](../../../blog/2019_05_19_substack/s_3.webp)

2. 관심 없는 독자들이 구독을 취소하는 데 더 쉽고 어색함도 덜 느껴집니다\. 직접 이메일을 보내는 것보다 훨씬 어색합니다 [^1]\.

   ![post](../../../blog/2019_05_19_substack/s_4.webp)

   텍스트가 약간 숨겨져 있는 것보다 더 명확했으면 좋겠어요\. 네\, 사실 구독 취소가 더 쉽게 되도록 만들고 싶어요\. 사람들은 스팸을 싫어하고\, 원하지 않는 사람에게 보내고 싶지 않거든요\. 가능하다면 구독 취소 옵션을 뉴스레터 맨 앞쪽으로 옮기고 싶어요\. 저도 아마 소수일 거라는 걸 이해해요\.

3. 더 전문적인 디자인의 뉴스레터와 풍부한 미디어 콘텐츠를 더 쉽게 포함할 수 있습니다\.

   > 유튜브와 비메오 영상\, 스포티파이 트랙\, 트윗을 게시물에 쉽게 삽입할 수 있습니다\. 관련 URL을 복사해서 붙여넣기만 하면 임베드가 마법처럼 나타납니다\. 이미지와 GIF를 드래그 앤 드롭할 수도 있습니다\.

   ![post](../../../blog/2019_05_19_substack/s_5.webp)

   Gmail이나 이 웹사이트에 미디어를 추가하는 것보다 훨씬 쉽습니다\. GIF 제작 [LICEcap](https://www.cockos.com/licecap/ 'LICEcap') 참고로\.

4. 클릭률 같은 독자 기반의 분석 자료입니다\. 기능이 더 추가되면 시간이 지나면서 개선될 것으로 예상합니다\.

   ![post](../../../blog/2019_05_19_substack/s_6.webp)

5. 결국 수익화 가능성 [^2]\. 비즈니스 모델도 간단한데\, 구독자에게 요금을 부과하기 시작하면 Substack에서 10\%의 수수료를 받습니다\. Substack은 월별 및 연간 요금제도 가능합니다\. 결제는 Stripe를 통해 처리되므로\, 아직 계정이 없다면 Stripe에서 계정을 만들어야 합니다\.

   > Stripe 계정을 Substack에 연결하면\, 저희가 귀하의 결제를 신뢰성 있고 안전하게 관리합니다\.

   ![post](../../../blog/2019_05_19_substack/s_7.webp)

## 제가 좋아하는 다른 것들은 다음과 같습니다

1. 고객 지원은 직접 관리자 문제를 처리하지 않아도 되도록 하는 것입니다\.

   > 신용카드나 로그인 문제\, 또는 기타 문제가 발생하면 저희가 대신 해결해 드립니다\. support@substack.com\.

   아직 사용해보진 않았지만\, 언젠가 필요할 때 갖고 있으면 좋네요\.

2. Substack의 \'소개\'와 \'구독해 주셔서 감사합니다\' 페이지는 빈 양식 대신 빠르게 서비스를 설정할 수 있도록 미리 채워져 있습니다\. 이 점은 설정 과정을 덜 고생시키는 작은 작은 요소라고 생각했습니다\.

3. 또한 가장 인기 있는 콘텐츠를 홍보하는 리더보드도 있는데\, 순위가 오르면 선순환이 생길 수 있습니다\. Substack은 이것이 발견에 도움이 된다고 주장하지만\, 저는 이 글 후반부에 제안을 드리겠습니다\.

   > 리더보드는 독자들이 훌륭한 출판물을 발견하도록 돕고\, 출판사가 새로운 독자를 찾는 데 도움을 줍니다\.

   ![post](../../../blog/2019_05_19_substack/s_8.webp)

   주요 출판사들의 짧은 프로필도 있습니다 [^3]\.

   ![post](../../../blog/2019_05_19_substack/s_9.webp)

4. 뉴스레터 환영 페이지는 독자에게 구독을 유도하지만 문제를 강제하지는 않아서 이해가 됩니다\. 샘플을 먼저 읽지 않고 구독하고 싶지는 않습니다\.

   ![post](../../../blog/2019_05_19_substack/s_10.webp)

5. 출판사로 가입한 후에는 창립자가 FAQ에서 질문을 못 받을 경우를 대비해 연락처도 제공합니다\. 아직 이메일을 보내지 않아서 실제로 답변이 오는지는 모르겠습니다\.

   ![post](../../../blog/2019_05_19_substack/s_11.webp)

6. 기업 대상 고객을 목표로 한다면 그룹 구독 기능도 있습니다\.

   > 조직\, 기업 또는 기타 기관이 회원을 위해 여러 구독을 구매하고 싶어 할 것 같다면\, 그룹 구독을 판매할 수 있습니다\.

## 다음 부분도 개선할 수 있다고 생각했습니다

1. 전체 메일링 리스트를 무료 구독자로 쉽게 업로드하는 방법이 없었고\, 양식에서는 이메일을 한 번에 하나씩만 업로드할 수 있었습니다\. 이메일을 업로드한 후 모든 독자 구독 설정을 수동으로 전환해야 했습니다 [^4]\. 이 점이 두 배로 짜증났는데\, 여러 리더의 설정을 동시에 전환할 수 없어서 각각 개별적으로 변경해야 했기 때문입니다\. 여러 구독자를 동시에 편집할 수 있는 기능이 있었으면 좋았을 텐데요\.

   ![post](../../../blog/2019_05_19_substack/s_12.webp)

2. 오래된 게시물을 업로드하는 것도 고통스러웠습니다\. 날짜와 시간 설정이 편집 레이아웃에 깊숙이 들어가 있어서\, 게시물을 업로드하고 개별적으로 원하는 정확한 날짜로 소급 올리는 데 시간이 걸렸습니다\. 글은 몇 개밖에 없었지만\, 더 긴 출판 이력을 가진 사람이 옛 콘텐츠를 올바른 날짜로 올릴 리가 없을 것 같아요\.

   > 마지막으로\, 다른 사이트의 아카이브에서 게시물을 가져오면\, 게시일을 올바르게 하고 올바른 게시일과 연관되도록 소급 날짜를 설정할 수 있습니다\. 이를 위해서는 게시물을 게시한 후 게시 버튼 왼쪽에 있는 설정에 들어가 원하는 날짜를 선택하세요

   ![post](../../../blog/2019_05_19_substack/s_13.webp)

3. 처음에는 계정 생성과 로그인에 문제가 있었습니다\. \'이메일 로그인 링크\'가 기본 옵션인 이유를 잘 모르겠고\, 이메일 요청 시 같은 로그인 페이지와 안내문으로 안내되는 루프가 발생했습니다\. 이 점이 혼란스러웠습니다\.

   ![post](../../../blog/2019_05_19_substack/s_14.webp)

4. 홈페이지에는 서비스에 대한 더 많은 정보를 제공하는 블로그 링크가 있습니다\. 하지만 블로그로 들어가기 위해 클릭하면\, 브라우저 뒤로 가기 버튼을 누르지 않고는 직관적으로 서브스택 홈페이지로 돌아갈 방법이 없습니다\. 드롭다운 메뉴는 돌아가 볼 수 없고\, 본문에는 반환 버튼도 없습니다\.

   ![post](../../../blog/2019_05_19_substack/s_15.webp)

5. 게시물 URL을 편집할 방법이 없는 것 같습니다\. 아래 예시에서는 \'곧 공개\' 플레이스홀더 게시물을 편집했는데\, 게시물 제목을 바꿔도 URL을 수정할 수 없었습니다\.

   ![post](../../../blog/2019_05_19_substack/s_16.webp)

6. \'열기\'와 \'클릭\'을 간단히 마우스오버로 표현하는 텍스트도 도움이 될 것 같습니다\. 상식적으로 생각하면 우리가 생각할 만한 것과 충분히 비슷할 것 같지만\, 여기서 명확한 설명을 얻으면 좋겠습니다\.

## 그리고 다음과 같은 추가 제안이 있습니다

1. 앞서 언급했듯이\, 리더보드가 있으면 좋지만 새로운 콘텐츠를 발견하는 데는 적합하지 않습니다\. 구독자가 빠르게 늘어나는 \'트렌드\' 콘텐츠를 위한 칼럼을 추가할 수도 있지 않을까요\? 또는 Substack 팀이 큐레이션한 덜 알려진 출판사들의 정기적인 순환 칼럼을 추가하는 것도 좋겠습니다\. 네\, 저는 분명히 작은 출판사로서 편향되어 있습니다\.

2. 저는 좋았어요 [this page](https://on.substack.com/p/what-you-get-when-you-start-a-substack 'substack features') Substack에서 얻을 수 있는 모든 기능에 대해 설명하지만\, 더 쉽게 찾을 수 있어야 한다고 합니다\.

3. 출판사가 가입한 후 공유되는 구글 문서가 있는데\, 유용한 정보가 담겨 있습니다\. 이 문서는 독립적으로 제대로 된 웹페이지가 되어야 사람들이 참고할 수 있습니다\. 예를 들어\, 저는 이미 그 링크를 잃어버렸습니다\.

4. 비밀번호 재설정 링크는 새 비밀번호를 한 번만 입력하면 됐고\; 잘못된 비밀번호 재설정을 줄이려면 새 비밀번호를 확인하거나 다시 입력해야 할 거예요\.

5. 링크된 각주를 쉽게 만드는 방법이 있을까요\?

6. 커스텀 도메인 추가를 다시 고려할까요\, 아니면 기술적으로 너무 번거로운가요\? 더 고급 커스터마이징이 부족한 점도 있는데\, 아마도 의도된 것 같아요\.

Substack은 비교적 쉽게 설정할 수 있고\, 전문적으로 보이며\, 구독자 기반에 대한 유용한 분석 기능이 있는 무료 뉴스레터 서비스를 제공합니다\. 저는 제 용도로 사용해본 적이 있습니다\. [monthly newsletters](https://avoidboringpeople.substack.com/ 'substack') 지금까지는 단순한 이메일보다 훨씬 나은 단계입니다\. 저는 여전히 메인 웹사이트는 Github Pages를 사용할 예정입니다\. 커스텀 도메인\, 별도의 페이지 레이아웃\, 서식 등 더 높은 수준의 커스터마이징이 가능하기 때문입니다\. 하지만 Substack에는 마음에 드는 점이 많습니다\.
