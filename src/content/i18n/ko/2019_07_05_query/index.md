친구가 최근에 새로운 프로젝트를 시작했어요\, [Query News](https://query.news/ 'Query')\. 이것은 프로젝트가 무엇인지에 대한 공략과 제가 제안한 몇 가지 방법입니다\.

## 워크스루

쿼리는 무엇을 목표로 하는 걸까요\? [Based on their own words:](https://query.news/s/we-launched-kinda)

> 이것을 시의적절한 뉴스를 위한 Quora라고 표현하는 것이 맞을까요\?

> 거의 그렇습니다\! 다만 Quora가 정확히 어떤 방향으로 되려 하는지는 잘 모르겠습니다\. 하지만 확실히 Quora는 좋은 출발점입니다\. 우리가 Quora에서 가장 망설이는 점은 답변 경쟁과 답변 협업 모델의 차이입니다\. 여기서 협업을 더 장려하는 것이 더 합리적일 수 있다고 생각합니다\. 하지만 두고 봐야겠죠\!

그래서 현재로서는 뉴스 이벤트가 발생하는 즉시 Q\&A 형식을 갖추는 것이 목표입니다\. 사람들이 주제에 대해 질문을 제출하고\, 누군가\(누가\?\)가 답변합니다\.

랜딩 페이지는 간단하며\, 질문을 시간 순서대로 정렬하고\, 가장 최근 날짜가 먼저 나옵니다\. 질문이 하루 안에 어떻게 정렬되는지는 잘 모르겠습니다\. 질문이 게시되면 순서가 고정된 것으로 추정됩니다\. 업데이트 시기가 순서에 영향을 주지 않는 것 같으니까요\. 모바일에서도 사이트가 잘 작동합니다\.

![post](../../../blog/2019_07_05_query/q_1.webp)

개별 주제를 클릭하면 해당 주제에 대한 더 자세한 Q\&A 페이지로 이동합니다\. 각 Q\&A 페이지마다 고유한 URL이 있습니다\. 페이지에는 뉴스 주제의 간략한 요약\, 출처 인용\, 질문 목차\, 그리고 질문 자체가 나옵니다\.

![post](../../../blog/2019_07_05_query/q_2.webp)

질문을 던질 수 있는 여러 프롬프트가 있는데\, 질문란에 입력하는 것만으로도 간단합니다\. 제가 알기로는 질문에 대한 즉각적인 중재가 없고\, 질문은 바로 페이지에 게시됩니다\. 사이트는 질문을 쉽게 할 수 있게 해줍니다\.

![post](../../../blog/2019_07_05_query/q_3.webp)

예를 들어\, 아래 질문을 올렸을 때\, 페이지가 새로고침되자 질문 목록 하단에 자동으로 올라왔어요\.

![post](../../../blog/2019_07_05_query/q_4.webp)

![post](../../../blog/2019_07_05_query/q_5.webp)

현재로서는 직접 질문에 답변할 수 있는 것 같지 않지만\, \'업데이트 제안\'을 하면 댓글을 편집자에게 전달할 수 있습니다\:

![post](../../../blog/2019_07_05_query/q_6.webp)

현재 주제와 질문 목록을 직접 둘러보실 수 있습니다 [here](https://query.news/ 'Query')댓글을 달고 싶은 것이 있는지 확인해 보세요\. 흥미로운 아이디어인 것 같네요\! 대부분의 뉴스는 일방적이며\, 대중에게 메시지를 전달하려는 목적이 있습니다\. 온라인 댓글란은 보통 엉망입니다\. 토론을 사이트의 중심으로 삼고\, 덧붙인 제품이 아니라\, 더 생산적인 사용 사례로 이어지길 바랍니다\. 만약 무언가를 읽고 \'X는 어쩌지\?\'라고 생각한 적이 있다면\, Query가 도움이 될 것입니다\.

대규모로 보면 어떻게 보일까요\? 주제별로 별도의 섹션을 두고\, 검증된 계정이 새 글을 올리고\, 관심 있는 독자들의 질문을 받아 답변하는 방식이 있을 수 있습니다\. 쿼리가 될 것입니다 _부지_ 다양한 주제에 대한 실시간 정보를 제공하며\, 실제로 더 깊이 파고들어 이야기가 전개되는 과정을 조사할 수 있습니다\.

질문과 제안으로 넘어가겠습니다\!

## 질문

1. 이것이 Quora와 어떻게 다른가요\? [Hacker News](https://news.ycombinator.com/ 'HN')\, 또는 [Reddit](https://www.reddit.com/)\?
   - Quora보다 더 협업적인 의도가 있는 것 같아서\(위 참조\)\, 여러 편집자가 질문에 답할 수 있는 기능을 만들 것 같아요
   - 그렇다면 스레드 대화는 허용하지 않고\, 대신 모든 내용을 질문당 하나의 답변으로 통합할 것 같습니다\. 이것은 Hacker News나 Reddit과는 다릅니다
   - 아마도 이것을 Quora X Wiki처럼 뉴스 현장 정보를 제공하는 곳이라고 생각할 수 있을까요\?
2. 이걸 어떻게 확장할 건가요\?
   - 질문 검토\(그리고 해당 기능이 구현되면 답변\)는 수동 편집자가 필요하며\, 모든 웹사이트에 그런 편집자가 있는 것은 아닙니다 [Steven Pruitt](https://www.cbsnews.com/news/meet-the-man-behind-a-third-of-whats-on-wikipedia/ 'Steven')\. 일부 스팸은 자동으로 삭제될 수 있지만\, 수동 중재 요소가 있을 가능성이 큽니다
   - 누가 질문에 답할 수 있는지\, 누가 해당 분야에 충분한 전문성을 가지고 논평할 수 있을지 어떻게 결정할 것인가\?
3. 모든 이해관계자에게 어떤 인센티브가 있나요\?
   - 창립자들에게\, [I think they want to create an experiment and see if there's demand from people to read news in a different format](https://query.news/s/we-launched-kinda/q/what-are-your-short-term-goals-for-the-query#q-52 'ST goals')
   - 질문자에게는 전문가가 답변한 주제에 대해 더 많은 정보\(이상적으로는 일반 뉴스보다 편향이 적은\) 정보를 얻기 위해서입니다
   - 결국 답변자들을 위해\, 명성을 쌓기 위해서\? 호의\? 지위 쌓기\?
4. 만약 다른 사람이 질문에 답할 수 있게 된다면\, 시간이 지나면서 사람들이 계정을 만들어야 한다는 뜻인가요\?
   - 질문은 여전히 자유롭고 익명으로 진행될 수 있지만\, 승인된 계정이 답변을 수정할 수 있을지도 모릅니다\.
   - 답변에 대해 하나의 통합된 \'쿼리 뉴스\' 목소리를 제시하려는 의도인가요\, 아니면 질문에 대해 여러 관점을 보여주려는 의도인가요\?

5. 이미지 기능이 있을까요\?

6. 답변의 질도 조절할 필요가 있을까요\?
   - Quora나 Reddit 같은 업보트\/다운보트 시스템이 사이트의 목적에 반하는 건지 잘 모르겠습니다

## 제안

1. 고정 [Query self-referential Q&A page](https://query.news/s/we-launched-kinda/ 'Query Q&A') 첫 페이지에 위치합니다\. 처음 홈페이지에 접속하는 사람은 사이트가 무엇에 관한 것인지 잘 알지 못할 것입니다\. 상단에 \"소개\" 탭을 두면 사이트가 무엇을 하려는지 이해할 수 있고\, Q\&A 페이지로 연결되는 간단한 링크도 있을 수 있습니다\.

   ![post](../../../blog/2019_07_05_query/q_7.webp)

2. \'팔로우\' 옵션이 정확히 무엇을 하는지 명확히 하고 싶습니다\. 이메일을 입력하면 해당 뉴스 주제의 모든 질문을 구독하는지\, Query의 모든 질문에 구독되는지\, 아니면 해당 주제에 관한 질문 하나만 구독되는지 잘 모르겠습니다

   ![post](../../../blog/2019_07_05_query/q_8.webp)

   \'팔로우\'를 클릭했음에도 참여가 뭘 해야 하는지 모르겠어요\:

   ![post](../../../blog/2019_07_05_query/q_9.webp)

3. 질문에 태그를 달고 검색 기능을 갖추는 것은 이 프로젝트가 성장할 때 도움이 되거나 심지어 필수적인 기능일 것 같습니다

4. 개별 질문마다 개별 공유 버튼이 있는데\, 주요 뉴스 주제 자체에는 없나요\?

5. 이게 로드맵에 있다고 가정하지만\, 언젠가는 사람들이 직접 뉴스 주제를 올릴 수 있도록 허용하는 것도 논리적인 다음 단계로 보입니다\.

6. RSS 피드를 통해 이걸 전달할 수 있는 방법이 있을까요\? 최근에 뉴스레터 형식으로 배포된 것 같아요\.
