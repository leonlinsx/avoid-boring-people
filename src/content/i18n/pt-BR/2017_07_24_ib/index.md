Quando estava saindo do banco de investimento\, quis refletir sobre o que havia aprendido\. Em parte por isso\, montei uma lista de temas que achei que um banqueiro júnior deveria tentar conhecer durante seu tempo lá\.

A lista não pretende ser abrangente\, nem acho que você possa ser especialista em todas as áreas depois de apenas alguns anos\. Admito que já esqueci algumas das áreas abaixo\. No entanto\, ainda acredito que é útil para referência\.

A lista está abaixo\:

  - Dividendos

## Relacionado ao Excel

- Melhores práticas
  - Fontes e comentários
  - Dados de entrada uma vez e referenciando essa entrada ao longo de todo o tempo
  - Layout e estrutura consistentes\, \'integridade matricial\'
  - Codificação por cores
  - Agrupamento\, não ocultação de linhas e colunas
  - Alinhamento de texto em vez de mesclar células
  - Evitar códigos rígidos em fórmulas sempre que possível
  - Índice para cálculos e números
- Fórmulas
  - Se for complicado\, separe\. Simples é bom
  - Vlookup vs Index Match
  - Escolha vs deslocamento
  - Produto sumário
  - Funções dos sumivos
  - Funções de contadores
  - Matrizes
  - Transposto
  - Funções voláteis
  - Funções de data
  - Função célula\(\)
  - Indireto
  - Patente
  - Iferror
  - Funções de arredondamento
  - Max\/min
- Funcionalidade do Excel
  - Tabelas de dados
    - Entradas vinculadas em vez de hardcodes
    - Tabelas de dados de tabulação cruzada
  - Vá para o Especial
    - Constantes\, fórmulas\, visíveis
  - Especial de Pasta
    - Links especiais para colar
  - Tabela dinâmica
    - Getpivotdata
  - Remover duplicatas
  - Gráficos de movimentação e dimensionamento com células
  - Cadeias nomeadas
  - Solucionador e busca de objetivos
  - Links externos vs abas drop\-in
    - Quebrando links\, mudando a fonte dos links
  - Códigos de formatação de células
  - Rastreamento de células precedentes\/dependentes
  - Verificação de erros\, verificação de integridade de fórmulas\, entrada em fórmulas
  - Tecla de atalho alt para inserir símbolos
  - Preencha para esquerda\/direita\/para baixo
  - Mover\, copiar\, esconder folhas
  - Formatos de compensação
  - Navegação do Excel
    - Ctrl Home e Fim
    - Ctrl página para cima\/baixo
    - Seta Ctrl
- Macros
  - Abas muito escondidas
